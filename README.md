# Hand-In-Tasks-Via-Trading-Computer-laptop-for-GAMMA
Hand In Tasks Via Trading Computer / laptop for Stalker GAMMA

## Preface: 
Honestly, I think the original Trading Computer is already approaching dangerous levels of quality of life, and with this, I'm certainly not helping the problem. But its niceeeee
## Description: 
Allows you to hand in / complete tasks in the same range as you can access traders straight from the trading computer, no need to run around Rostok anymore handing in tasks ! Not sure if theres going to be any issues with this but oh well.  Double Click the "Hand in all tasks" button to hand in the tasks. There is a delay between handing in the tasks because fetch quests bug out if you hand them in too fast
